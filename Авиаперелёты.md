Задание 6 --- Компании, летавшие на Boeing

Условие:
Какие компании совершали перелёты на Boeing?

Поле результата: name

SELECT DISTINCT Company.name
FROM Trip
INNER JOIN Company
    ON Trip.company = Company.id
WHERE plane LIKE '%Boeing%';

Задание 12 --- Количество пассажиров на рейсах

Условие:
Вывести идентификаторы всех рейсов и количество пассажиров на них.

На некоторых рейсах пассажиров может не быть. В таком случае необходимо
вывести 0.

Используется AS count для корректной проверки результата.

Поля результата: id, count

SELECT Trip.id,
       COUNT(Pass_in_trip.Passenger) AS count
FROM Trip
LEFT JOIN Pass_in_trip
    ON Trip.id = Pass_in_trip.trip
GROUP BY Trip.id;

Задание 14 --- Города, которые посетил Bruce Willis

Условие:
В какие города летал Bruce Willis?

Поле результата: town_to

SELECT Trip.town_to
FROM Pass_in_trip
INNER JOIN Trip
    ON Trip.id = Pass_in_trip.trip
WHERE Pass_in_trip.passenger = 1;

Задание 15 --- Прибытие Steve Martin в Лондон

Условие:
Вывести идентификатор пассажира Steve Martin и дату и время его прилёта
в Лондон (London).

Поля результата: id, time_in

SELECT Passenger.id,
       time_in
FROM Passenger
INNER JOIN Pass_in_trip
    ON Pass_in_trip.passenger = Passenger.id
LEFT JOIN Trip
    ON Pass_in_trip.trip = Trip.id
WHERE town_to = 'London'
  AND Passenger.name = 'Steve Martin';

Задание 28 --- Рейсы из Ростова в Москву

Условие:
Сколько рейсов совершили авиакомпании из Ростова (Rostov) в Москву
(Moscow)?

Используется AS count для корректной проверки результата.

Поле результата: count

SELECT COUNT(Trip.id) AS count
FROM Trip
WHERE town_from = 'Rostov'
  AND town_to = 'Moscow';
